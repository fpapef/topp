- La montre peut piloter la nacelle avec les mouvements du poignet : touche le bouton Gestes, puis pointe la main là où tu veux que la caméra aille.
- Dans les réglages du téléphone : activation par un appui (marche/arrêt) ou en maintenant le bouton, sensibilité, inversion des sens.
- Nouveau bouton sur la montre pour passer d'une caméra à l'autre.

Installe `Topp-telephone-1.3.apk` sur le téléphone et `Topp-montre-1.3.apk` sur la montre (voir le README). Les deux s'installent par-dessus les versions précédentes.
